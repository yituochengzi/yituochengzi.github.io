135按评分分糖果

发表于 2023-02-01 更新于 2026-05-05 分类于 算法 阅读次数： Waline：

问题描述

一群孩子站成一排，每个孩子有自己的评分。现在需要给这些孩子发糖果，规则是如果一个孩子的评分比自己身旁的一个孩子要高，那么这个孩子就必须得到比身旁孩子更多的糖果；所有孩子至少要有一个糖果。求解最少需要多少个糖果
输入：孩子评分[1,2,1,2,1,2,1,3,4]
输出：所需最少糖果数

我的题解

  • 先排序
  • 数字类别有几类
  • 最小的分一颗糖，按类别依次递增
  • 把糖果加起来

题目理解错误：顺序固定，不能排序，只要求，比隔壁评分高，糖果数就比他多1，不是评分相同就拿一样糖果
纠正后的题解：

  • 定边界，数组小于2时(1,0)，返回len
  • 初始化每个人只有一颗糖果
  • 从左到右遍历，左大于右，左 + 1
  • 从右到左遍历，右大于左，右 + 1
  • 计算总和

1.索引越界问题

解决办法：分两次遍历
第一次，从左往右遍历，（1，size）
比较candy[i] > candy[i - 1]，提前从1开始，i = 1时，i - 1为0，不会越界了

同理，
第二次，从右往左遍历，（size - 2, -1, -1）
因为最右边的数下标为size - 1,必须从倒数第二个开始，不然i + 1就超索引了

2.糖果加法

解决办法：
左大于右，左糖果数 = 右糖果数 + 1
右大于左，右糖果数 = 左糖果数 + 1
