435无重叠区间

发表于 2023-02-01 更新于 2026-05-05 分类于 算法 阅读次数： Waline：
  1. 无重叠区间
  • 难度：中等

题目描述

给定一个区间的集合 intervals ，其中 intervals[i] = [starti, endi] 。返回 需要移除区间的最小数量，使剩余区间互不重叠。

示例 1

输入：intervals = [[1,2],[2,3],[3,4],[1,3]]
输出：1
解释：移除 [1,3] 后，剩下的区间没有重叠。

题解思路

  1. 先把区间按照结尾大小进行增序排序
  2. 选择结尾最小且和前一个区间不重叠的区间
  3. 保留最多的区间

思考问题

  • 边界是啥？
  • 区间特性：左边不能大于右边
  • 输入啥会超出功能范围
  • 特殊情况是啥？
  • 输入空的列表，或者只有一个区间的列表
  • 怎么让列表按结尾排序？
  • 什么情况是区间重叠

问题再览

1. 索引问题

range(1, len(intervals)-1) 取不到 len(intervals)-1，所以漏测一个。

改为：range(1, len(intervals))

2. 条件错乱

判断条件是 intervals[i][0] < end。

初始化 end 是第一个区间，后一个元素的区间开始小于前一个区间的结尾，说明区间重叠。count 此时代表去除的区间元素，而非保留元素，会导致返回结果时产生错误。

3. 何时改变 end

end 更新在条件之外，代表每次遍历都更改 end，即列表里的区间都遍历了一遍，每个 end 只和前一个 end 比较。该错误操作导致 end 更新为了一个将要被移除的区间。实际上当区间不重叠时（即不满足条件时），才需要更新 end。
